## 📌 About The Project

This repository contains the source code for my personal portfolio website.

The website was developed using **HTML, CSS, and JavaScript** to create a responsive and interactive personal portfolio.

The main purpose of this project is to provide a centralized platform where recruiters, developers, and visitors can learn more about my technical background, education, skills, projects, and professional profiles.

The project also demonstrates my understanding of:

- Front-end web development
- Responsive web design
- JavaScript-based interactivity
- DOM manipulation
- UI animations
- Navigation and user interaction
- Integration of external frontend libraries

---

## ✨ Features

- 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile screen sizes.
- 👨‍💻 **Personal Introduction** — Introduction section containing my name, developer profile, and professional information.
- 🎓 **Education Section** — Displays my academic background and educational achievements.
- 🛠️ **Skills Section** — Highlights my technical skills and development technologies.
- 🚀 **Projects Section** — Provides a dedicated area for showcasing my development projects.
- 📬 **Contact Section** — Provides contact information and a way for visitors to get in touch.
- 🔗 **Developer Profiles** — Links to my GitHub, LinkedIn, LeetCode, GeeksforGeeks, and Coding Ninjas profiles.
- 🎨 **Interactive User Interface** — Includes navigation effects, animations, typing effects, and interactive UI elements.
- 📐 **Responsive Navigation** — Navigation adapts to different screen sizes for a better user experience.
- ⚡ **Lightweight Frontend** — The project uses a simple frontend architecture without requiring a backend server.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/UniverseOfYograj/port-folio-project.git
```

### 2. Navigate to the Project Directory

```bash
cd port-folio-project
```

### 3. Open the Project

Open the project in Visual Studio Code or your preferred code editor.

You can open `index.html` directly in a browser. For development, you can use the Live Server extension in Visual Studio Code.

---

## 💻 Running the Project

This is a static frontend project, so no backend server or database is required.

Simply open:

```text
index.html
```

in a modern web browser.
